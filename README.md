# Banking-Bureau-PowerBI-Analytics
Interactive Power BI dashboard project for banking analytics, covering market share, risk monitoring, loan acquisition, portfolio trends, geographic analysis, Top N rankings, and portfolio vintage analysis.

# Project Objectives
- Analyze banking portfolio and market share.
- Monitor risk indicators and delinquency patterns.
- Understand loan acquisition trends.
- Track portfolio performance over time.
- Compare portfolio performance across geographic locations.
- Identify top-performing contributors or categories.
- Analyze portfolio performance by vintage or origination period.

 # Tools & Technologies
- Power BI Desktop – Dashboard development and visualization
- DAX – Measures and KPI calculations, where implemented
- Power Query – Data cleaning and transformation, where implemented
- Excel / SQL – Data preparation or querying, if used in the project

# Dashboard Pages
1. Market Share Analysis:
Analyzes portfolio share and compares contributors or categories using KPI cards, charts, and detailed tables.

2. Risk Meter:
Presents risk-related indicators and comparisons to help identify potentially higher-risk segments and locations.

3. Loan Acquisition Analysis:
Explores loan acquisition patterns, category composition, and changes over time.

4. Portfolio Trends:
Tracks portfolio performance across reporting periods using time-series visualizations.

5. Top Geographies:
Compares portfolio distribution across geographic locations using maps and ranking charts.

6. Top N Analysis:
Highlights leading entities or categories based on selected metrics and filters.

7. Portfolio Vintage:
Compares portfolio outcomes across origination periods to explore differences in portfolio and delinquency performance.

# Key Features
- Interactive KPI cards and visualizations
- Filter and slicer-based analysis
- Time-series trend analysis
- Geographic portfolio comparisons
- Ranked Top N analysis
- Vintage-based portfolio analysis
- Banking-themed report design with Introduction and Thank You pages
